# 原架构与公共适配

AEGIS PRIME负责治理、派发、验收与审计；ORION S1/S2保留独立的扫描、执行内核、账本、风险与退出；NEXUS负责研究；JEV负责独立只读观察、结果研究与影子，无订单权限。

数据流：行情/账户读取 → 扫描/确认 → 执行预检与风险保留 → 唯一订单端口 → 保护/对账/SQLite审计 → 发布快照 → 原驾驶舱。JEV读取证据后独立研究，不控制执行心跳或自动放大仓位。

默认公共安装把真实网络端口换为FakeS1Venue；脚本直接组装原execution-runtime与原引擎，构造测试用BBO/Tick和账户帧，并强制禁用fetch。运行回执写入.runtime/public-demo，Vite本地预览中间件将回执映射给原S1/S2页面。Cloudflare API保留原处理代码，默认分支只允许本地合成读取，写入405。

原站点的托管项目ID被移除，D1/R2配置只保留绑定名占位。JEV页面沿用原组件、默认空状态。应用源码中的非默认真实集成分支是后续扩展点，不能当成开箱部署结果。

原机运维与历史授权不分发。ops提供不含密钥和主机绑定的本地Compose模板；容器方式为可选，未实际验收前不要宣称可生产部署。
