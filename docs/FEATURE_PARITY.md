# 原项目功能对应与验收范围

基于明确GitHub commit导出，不以本地未提交代码为准。算法模块尽量保留原目录、导入和接口，适配仅针对公共发行、Demo地址、原操作者标识和本地安装。源文件清单及上游SHA256见 governance/upstream-source-manifest.json。

| 原项目功能 | 开源版处理 | 默认验收 |
| --- | --- | --- |
| S1/S2原驾驶舱与候选/持仓/流水页面 | 保留原React组件与样式，新增模拟模式横幅 | 两个本地页面 |
| 4H×1H交汇、15M确认、候选发现去重 | 保留原扫描和共享函数，不替换MA | 可移植组件测试；默认演练注入合成信号 |
| S1/S2订单内核、幂等、成本风险、止损保护与记账 | 保留原内核、生命周期和端口契约 | 原引擎 + FakeS1Venue，SQLite审计与证据段 |
| 实时账户读取、用户流、BBO/Tick归档 | 保留源码接口 | 合成证据；真实Demo需独立配置和验收 |
| JEV观察/决策、结果研究、影子与界面 | 保留原源码与三个面板 | 默认只读空状态，未启动推理/影子 |
| SMC执行/工作台 | 保留源码和页面 | 默认不配置，写API关闭 |
| D1、Drizzle迁移、Worker快照API | 保留原源码 | 本地默认预览适配器；独立云部署需自己的资源 |
| TradingView Pine | 保留当前源码，不导入私人云端脚本、截图和发布记录 | 源码分发；需用户在自己的平台编译 |
| 原主机恢复、秘密分发、实例专属发布 | 不导入私人操作流程；旧源码入口有直接启动保护 | 不能用于一键安装；新ops模板仅本地模拟 |
| 历史个人授权、账本、事故样本与记忆 | 不分发 | 不可推断为新用户权限 |
| 旧V1/V3/V4等谱系 | 保留可用源码供参考，不自动恢复 | 不作为默认启动目标 |
| 后续未提交R23等工作区变更 | 不混入本次来源基线 | 未宣称包含 |

保留原引擎不等于保留私人实盘状态。源码中的历史模式枚举LIVE用于运行原合成执行测试，端口实际绑定本地FakeS1Venue，网络强制关闭；它不代表真实资金或交易所请求。

默认演练每次新建隔离SQLite环境，用相同合成信号验证完整执行。不是持续交易策略、市场回测或业绩轨迹。看板使用本次演练的仓位回执，历史盈亏不造数。扫描模块在测试中单独验收，不冒称演练信号由在线扫描器生成。
